ฝึกกด 8 ปุ่มสำคัญเพื่อฟังเสียงภาษาอังกฤษสำเนียงแท้และคำอธิบายภาษาไทย

⭐ 8 ปุ่มสำคัญที่รองรับการฝึกกด ⭐

Enter : ขึ้นบรรทัดใหม่
Backspace : ลบซ้าย
Shift : พิมพ์ตัวบน
Caps Lock : พิมพ์ใหญ่
Space Bar : เาะเว้นวรรค
Tab : เว้นระยะกว้าง
Delete : ลบขวา
Windows : เปิดเมนู
